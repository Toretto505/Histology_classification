В домашке по KNN нужно было проверять разные метрики (косинусную и евклидову), нужно было перебирать разное число соседей, пробовать взвешенное голосование и обычное (в этом задании обычное не пробовал, сразу взвешенное брал), расширять выборки с помощью разных преобразований (повороты, отражения, фильтр гаусса и разные морфологические преобразования). В этом задании я решил для KNN проверять разные метрики и количество соседей, а для SVM смотрел влияние поворотов и отражений изображений.

В домашке по SVM проверяли разные ядра (в этом задании только rbf использовал), подбирали значение параметра C (отвечает за штраф за нарушение зазора между классами и неправильную классификацию объектов), строили разные графики, но в этом задании ничего не строил.

Теперь объясню LBL.

LBL1 - задание я делал не в колабе, а в vs code, потому что на моем компе всё считается быстрее, чем в бесплатной версии колаба. Обученный SVM сохранял в файл через библиотеку joblib (сохранил именно модель, а не веса). В колабе отдельно проверил, что модель загружается и работает нормально.

LBL2 - это моя реализация класса Model. resnet50 без последнего слоя даёт признаки, SVM учится на признаках 8 видов каждой картинки (исходная картинка + повороты на 90, 180, 270 и отражение каждой из них). save сохраняет обученный SVM в файл best.joblib, load скачивает этот файл с google drive.

LBL3 - функции для поворотов и отражений картинок, часть реализации прям из домашки по KNN взял.

LBL4 - тестировал разные гиперпараметры для KNN на tiny (без кросс-валидации).

LBL5 - тестировал разные гиперпараметры для KNN на small.

LBL6 - тестировал разные гиперпараметры для SVM на small.

LBL7 - пробовал сделать ансамбль из KNN+SVM, но отличие в точности у SVM и SVM+KNN настолько маленькое, что я решил ансамблем не пользоваться дальше.

LBL8 - сделал функции load_features_8, которая считает признаки 8 видов для train_small и сохраняет в файл (чтобы не пересчитывать). predict_views даёт предсказание по одному виду и по сумме 8 видов. cross_val_svm обучает SVM на кросс-валидации в четырёх вариантах (без всего, аугментация только на train, аугментация только на test, аугментация на train и test). И сравнивал resnet18 и resnet50.

LBL9 - посчитал признаки test_small для resnet50 и загрузил из файла признаки train_small.

LBL10 - обучил два SVM на признаках resnet50. Первый на исходных изображениях, второй на всех восьми вариантах каждого изображения.

LBL11 - проверил их на test_small с аугментацией test и без. Лучше всего, когда на обучении 8 видов картинки и на тесте по 8 картинкам предсказываем.

LBL12 - замерил время на 1000 картинках из train. Хотел оценить, сколько займет всё обучение.

LBL13 - обучил финальную модель на всём train, сохранил в best.joblib и загрузил на Google Drive.

LBL14 - посмотрел точность на test и на test_tiny(test_tiny решил проверить, чтобы сравнить потом с предсказаниями после перезапуска ядра).

LBL15 - без этого импорта ячейка после LBL16 не работала.

LBL16 - проверил, работают ли предсказания после перезапуска ядра. Модель скачалась через load(), на test_tiny метрики такими же получились, как до перезапуска.


Результаты.

На train_small с кросс-валидацией следующие результаты:

1) Лучший результат KNN с признаками resnet50 составил 93.25% Balanced Accuracy (косинусная метрика, k=4).

2) Для SVM лучший результат с resnet18 составил 96.89% при использовании аугментаций при обучении и аугментаций при предсказании.

3) При использовании resnet50 в тех же условиях результат составил 97.47%. Поэтому для финальной модели была выбрана resnet50.


На test_small были сравнены четыре варианта использования аугментаций с resnet50 и SVM:

Без аугментаций 96.44% Accuracy.

Аугментации только при предсказании 96.83%.

Аугментации только при обучении 96.72%.

Аугментации и при обучении, и при предсказании 97.50%.


Финальная модель была обучена на train. При тестировании на test получены следующие результаты:

Accuracy — 98.24%.

Balanced Accuracy — 98.24%.


На test_tiny до и после перезапуска среды выполнения Accuracy и Balanced Accuracy составили 98.89%.

В итоге получилась следующая модель - для извлечения признаков используется предобученная resnet50, для каждого изображения создаются 8 его вариантов, все 8 вариантов пропускаются через resnet50. На полученных признаках обучается SVM с параметром C=10, RBF-ядром и gamma='scale'. При предсказании изображение также преобразуется в 8 вариантов, для каждого варианта SVM считает decision_function. Оценки всех восьми вариантов складываются, после чего выбирается класс с максимальной суммарной оценкой.
